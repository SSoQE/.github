# Canonical repository overlay

This is the public source repository for SSoQE agent instructions.

- Changes to `.ai/`, `AGENTS.md`, or synchronization tooling require focused validation with `Rscript R/test_agent_instructions.R`.
- Organization-profile documentation and the SSoQE logo asset have separate content ownership. Do not change them as a side effect of instruction maintenance.
- Do not publish a static inventory of organization repositories. Discover the active set dynamically during rollout.
